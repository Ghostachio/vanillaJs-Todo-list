# 📝 Todo List App

A simple and minimal **vanilla JavaScript Todo List App** that allows you to manage your daily tasks with ease.  
You can **add, delete, mark all as done, clear all tasks, and view the task count** in real time.

---

## ✨ Features
- ➕ Add new tasks  
- ❌ Delete tasks  
- ✅ Mark all tasks as done  
- 🗑️ Clear all tasks at once  
- 🔢 View the number of tasks left
